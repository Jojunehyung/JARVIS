■ 과제
"인생 상태창(Life Manager)" — 목표(OKR)를 세우고, 실행을 증거로 증명하고,
시장 기준으로 냉정하게 평가받는 인생 관리 앱(모바일 웹)의
① UI 전 화면 디자인과 ② 일러스트 세트를 디자인 캔버스로 만들어줘.

이미 동작하는 React 앱(life-rpg.jsx, Tailwind)이 있고, 아래에 실제 구현 스펙
(색 토큰·컴포넌트 패턴·카피 원문)을 그대로 적었다. 이 캔버스의 산출물은
이후 Claude Code가 읽고 기존 코드에 반영한다. 따라서 "산출물 규약"이 최우선이다.
목표는 현재 구조·정보를 유지한 채 시각 완성도를 끌어올리는 리디자인이다 —
정보 구조를 새로 발명하지 말 것.

■ 산출물 규약 (Claude Code 반영 가능 조건 — 반드시 준수)
1. 화면 아트보드는 390×844 세로 모바일 프레임, 1컬럼(코드상 max-w-md 중앙 정렬).
   다크 단일 테마(라이트 모드 없음).
2. 색은 아래 [팔레트]의 Tailwind 토큰만 사용하고, 각 색면에는 토큰명을 주석으로
   남겨라(예: "bg-zinc-900", "text-cyan-300"). 임의 hex 신규 도입 금지 —
   단, 일러스트(인물·트로피)는 아래 일러스트 전용 hex 팔레트를 쓴다.
3. 모든 텍스트는 실제 텍스트로 넣고(이미지화 금지), 카피는 아래 원문을 그대로 써라.
   새 카피를 제안하고 싶으면 문구 앞에 [제안] 을 붙여 기존 카피와 구분하라.
4. 각 아트보드·주요 블록에 코드 컴포넌트 심볼명을 작은 라벨로 남겨라:
   Shell / HomeTab / GoalsTab / QuestTab / GrowthTab / AddGoalModal / AddQuestModal /
   EvidenceModal / StudyVerifyModal / ActivityLogModal / PromoteModal / RoleModelModal /
   RoleAdviceModal / CatalogModal / MetricsModal / Overlay-gradeup / Overlay-achieve /
   PortraitSprite / TrophySvg / Bar / DiffBadge / CertBadge / Chip / SectionLabel.
5. 일러스트는 플랫 벡터 스타일(단순 path + 그라디언트, SVG 코드로 재현 가능한 수준).
   외부 이미지·사진 텍스처·복잡한 필터 금지. 비율 규약: 인물 4:5(viewBox 120×150),
   트로피 5:6(viewBox 30×36), 프로필 사진 슬롯 256×320.
6. 아이콘은 lucide 선형 아이콘만. 현재 사용 11종: Flag, Target, ClipboardList,
   TrendingUp, Plus, X, Check, Lock, Trophy, Star, RotateCcw.
   필요 시 lucide에 실존하는 아이콘만 추가하고 이름을 라벨로 남겨라.
7. 게임 연출 재도입 금지(사용자 확정 폐기): XP·레벨·골드·상점·크리티컬·랜덤 보상·
   보스·스토리·미연시 요소를 그리지 말 것. 등급(0~9)·성취 트로피·스트릭(🔥)·
   실드(🛡)는 게임 요소가 아니라 유지 대상이다.
8. 카피 톤 = 현실·객관: 격려·낙관·희망 문구 금지. 수치와 사실만.
   "12%p 뒤처짐", "목표 기여 없음 — 목표 진행에 기여하지 않은 성취입니다" 같은
   문구를 완곡화·은폐하지 말 것. 진행률 옆에는 항상 시간 경과율과 페이스 판정이 붙는다.

■ 제품 요약 (문맥)
- 구조: 파트(인생 영역, 등급 0~9) → 목표(OKR: 기한 + 핵심결과 KR 1~4개)
  → 퀘스트(하루분량 일일 실행 + 자격·시험·학습 "마일스톤").
- KR 4유형: 수치(metric) / 횟수(count) / 시험(exam) / 자격(cert).
  퀘스트는 목표에서만 생성되고, 자격·시험은 KR에서 원클릭 등록(KR 브리지)으로만 만든다.
- 완료 검증: 자격·시험 = 합격증/성적표 사진 필수, 학습 = 요약+산출물,
  독서 = 독후감, 미팅 = 회의록, 운동 = 측정 기록(선택). 증거 없는 완료는 없다.
- 화면: 하단 4탭(홈/목표/퀘스트/성장) + 온보딩 6스텝 + 모달 10여 종 +
  전면 오버레이 연출 2종(RANK UP / ACHIEVEMENT) + 토스트.
- 파트 등급명 0~9: 지망생·견습·초심자·실무자·숙련자·전문가·리더·마스터·거장·정점.
  성취 등급 문자: A(amber) B(violet) C(sky) D(emerald) E(zinc).

■ 타이포·리듬 규칙
- 숫자·D값·P·퍼센트·D-day·시스템 라벨(LIFE MANAGER, RANK UP, ACHIEVEMENT)은
  전부 font-mono. 섹션 캡션은 text-xs tracking-widest.
- 본문 대부분 text-xs~text-sm, 모달 제목 text-base font-bold,
  오버레이 히어로 text-2xl font-black. 수직 리듬 space-y-4(섹션)/space-y-3(카드 내부).
- 진행바(Bar): h-2 rounded-full, 트랙 bg-zinc-800, 필 색은 문맥색(목표 cyan-400,
  달성 emerald-400, 지표 3색), width 전환 0.7s ease-out.

■ 일러스트 브리프 (A11 + 각 화면 배치용)
1) 인물 초상(PortraitSprite 리디자인) — 반신 버스트샷, 4:5(viewBox 120×150).

   다크 UI 위에서 인물을 띄우는 핵심 장치다.
   커스터마이즈 조합을 그대로 지원해야 한다:
   피부 4종 #f6d7b0 #eec39a #d9a066 #a06a42 /
   머리색 6종 #2b2b2b #5b3a1e #a9714b #c9a227 #7a4fbf #d94f6b /
   의상 6종 #f59e0b #22d3ee #a78bfa #34d399 #fb7185 #94a3b8 /
   헤어스타일 5종(기본·단발·장발·포니·스포츠) / 표정 3종(기본·미소·진지) /
